# ---------------------------------------------------------------------------
# NÚCLEO — lo mínimo para que el escritorio se vea y se sienta igual.
#
# Uso:   ./install.sh paquetes --core-only
#        make instalar-nucleo
#
# Si estás montando una PC nueva con prisa, esta es la lista que importa.
# Después corres el instalador completo (o `make instalar`) para el resto.
#
# Reglas:
#   - Mezcla repos oficiales y AUR a propósito: el instalador detecta solo de
#     dónde viene cada paquete.
#   - `# hw:` filtra por hardware (ver scripts/lib/hardware.sh).
#   - Todo lo que NO esté aquí pero sí en oficiales.txt/aur.txt se instala con
#     el tier `full` (el predeterminado).
# ---------------------------------------------------------------------------
